# PREVENT AHA parity archive

Goldens and tooling to compare this app’s OpenCVDRisk `$evaluate` path against
the AHA's PREVENT equation outputs for the eight synthetic catalog patients.

## Files

| File | Role |
|------|------|
| [`prevent-aha-goldens.csv`](prevent-aha-goldens.csv) | **Archival source of truth** — frozen inputs + AHA-aligned expected risks |
| [`prevent-aha-comparison.csv`](prevent-aha-comparison.csv) | Regenerated by `npm run compare:prevent-aha` (not authoritative) |

## Encoding rules

- UTF-8 CSV, RFC4180 quoting, decimal point `.`
- Booleans `true`/`false`; empty cell = absent
- Units in column names
- `age_years` is frozen with `age_as_of` — do not recompute from DOB when comparing
- Scenario `prefill_as_ui`: chart prefill values including ZIP→SDI when ZIP resolves
- Synthea ZIP `00000` treated as absent

## `aha_status` values

| Status | Meaning |
|--------|---------|
| `ok` | 10y and 30y risks present (age ≤ 59) |
| `ok_no_30y` | 10y only (age ≥ 60) |
| `refused_exclusion` | Calculator refused (e.g. known CVD) |
| `incomplete_inputs` | Required input outside validated range / missing |
| `manual_review` | Needs human review |

## Scripts

```bash
# Validate goldens schema
npm run validate:prevent-aha

# Compare goldens aha_* vs Library/OpenCVDRisk/$evaluate (+ local prevent-math)
npm run compare:prevent-aha
```

Env: `FHIR_BASE_URL` (default `http://localhost:8080/fhir`).

## Pass criteria

Overlapping outcomes **10y/30y × total CVD, ASCVD, HF** must match within **0.1**
percentage points. CHD/Stroke are app-only (S12); not compared to AHA web UI.

When goldens include `aha_prevent_age` / `aha_30y_cvd_percentile`, those must match
app/TS exactly (integer years / percentiles). Empty AHA cells are skipped.
