Architecture

This app helps clinicians estimate cardiovascular risk and support lipid management decisions using patient health records.

Decision support only

Results are guidance for clinicians. They are not orders and do not replace clinical judgment.

How the application works

The calculator loads values from the patient chart, lets the clinician review or change them, then asks the health data server to compute risk scores.

Risk scoring

Prefill fills the form from the chart. Calculate re-runs scoring with the current form values.

Standalone mode

Connect to a health data server in Settings, then search for a patient or open a patient data file. Scoring rules and terminology must already be installed on that server.

SMART-on-FHIR mode

The electronic health record opens the app with a patient already selected. Scoring uses that chart on the EHR’s server.

How clinical logic is packaged

Scoring rules and related terminology ship as a FHIR NPM package. Install that package on the FHIR server before scoring runs.

  • Rules and terminology are installed once, then reused for each calculation.
  • The browser does not score patients itself; the server runs the installed rules.
  • Installed terminology must match what the scoring rules expect.

OpenCVDRisk and PREVENT™

OpenCVDRisk is an open-source implementation of the AHA PREVENT™ risk equations for adults ages 30–79 without known cardiovascular disease. It is not an official AHA product and is not affiliated with or endorsed by the AHA.

Model: Khan SS et al., Circulation. 2024;149:430-449. DOI: 10.1161/CIRCULATIONAHA.123.067626. PREVENT Risk Age: Krishnan V et al., JAMA Cardiol. 2025. DOI: 10.1001/jamacardio.2025.2427.

Guideline basis

After a successful OpenCVDRisk calculation, the accepted session (risk, model, overrides) is held in memory and passed to the Guideline page. That page evaluates Library/LipidManagement with the same overrides, optional clinician confirmations (tri-state Yes/No/Unknown), and returns Appendix G pathway status plus Recommendation 1–24 applicability. Mermaid visualizes Boxes 1–21; CQL remains the source of truth. Source: VA/DoD Lipids CPG December 2025 (PDF final 2026-01-06), Appendix G and Table 4.

  • Box 14 five-year practice point is distinct from Recommendation 2 (insufficient evidence for frequency).
  • Box 15 reassessment reminder is distinct from Recommendation 15 (continue therapy if LDL-C <30).
  • Box 20 presents fixed-dose and treat-to-target without preference; Recommendation 17 is neither for nor against.
  • Box 6 six-week MI/ACS/CABG/PCI cue is narrower than Recommendation 24’s recent CHD rehab population.
  • Medication outputs are decision-support option sets, never orders.
  • Secondary prevention (Box 5) uses clinical ASCVD Condition codes; CAC score Observations alone do not establish ASCVD.
  • Known non-automatable judgments: life expectancy <5 years, VHR temporal criteria, escalation, patient preference, triglyceride persistence, statin intolerance, CAC clinical-risk class.
