About

The application provides lipid management guidance based on FHIR patient records. In it based on clinical decision support guidelines from the U.S. Department of Veterans Affairs, using cardiovascular disease risk scoring algorithms aligned to the American Heart Association PREVENT™ algorithms. It uses Clinical Quality Language (CQL) on the FHIR R4 data model.

Decision support only

Outputs from this application and its CQL libraries are decision support signals. They are not autonomous clinical orders and are not a substitute for clinical judgment.

How the application works

The browser application talks to a FHIR server that stores patient data, clinical terminology (ValueSets), and decision-support logic (CQL Libraries). Risk scoring uses that server’s Library/$evaluate operation: once to preload chart values into the form, and again when the clinician calculates risk. Local form overrides for review do not change the chart data sent to $evaluate.

Risk scoring interaction

Major steps when using the OpenCVDRisk calculator: CQL preload of chart inputs, form prepopulation, optional clinician overrides, manual recalculation, server-side CQL processing, and returning scores to the UI.

Standalone mode

In demos and local setups, optionally upload Libraries and ValueSets with the Loader, search and select a patient, then run the same preload → prefill → calculate path against that FHIR server.

SMART-on-FHIR mode

The EHR launches the app against its FHIR server. After SMART authorization and patient context, the calculator uses the same CQL preload and risk $evaluate steps as standalone mode.

How clinical logic is packaged

Clinical Quality Language (CQL) source files and ValueSet terminology are shipped with the application, then loaded onto the FHIR server as standard FHIR resources before evaluation.

  • CQL files under public/cql/ become FHIR Library resources (contentType: text/cql, base64-encoded body).
  • Terminology under public/value-sets/ is already FHIR ValueSet content inside transaction Bundles; the Loader posts them to the server.
  • CQL valueset URLs must match the ValueSet.url values stored on the server.
  • At runtime the browser does not interpret CQL itself for decision support; the FHIR server evaluates the uploaded Library against patient data.

OpenCVDRisk and PREVENT™

The OpenCVDRisk Calculator and library are an open-source implementation of the American Heart Association (AHA) PREVENT™ algorithms for adults ages 30–79 without known cardiovascular disease. They do not use AHA source code or AHA assets requiring a license from the AHA. This is not an official AHA product and is neither affiliated with nor endorsed by the AHA.

Statistical model: Khan SS et al., Circulation. 2024;149:430-449. DOI: 10.1161/CIRCULATIONAHA.123.067626.

Guideline basis

LipidManagement CQL maps the VA/DoD Clinical Practice Guideline on Lipid Management for Cardiovascular Disease Risk Reduction (2025), including the adult management algorithm (Appendix G / figure page 20).
